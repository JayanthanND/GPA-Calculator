# GPA Calculator

A fast, offline-friendly GPA calculator for the 10-point scale. Type credits and grades directly and see the GPA update live.

**Live site:** https://jayanthannd.github.io/GPA-Calculator/

## Features
- Type credits and grades freely (decimals supported), no dropdowns
- Live GPA while typing, plus a full result with subjects, credits and points
- Input validation with highlighted fields
- Autosaves on your device, works offline, light and dark mode
- Copy result, add or remove subjects, mobile-first layout

Credit-weighted average: GPA = sum(credits × grade) / sum(credits).
